# Кватирка

Свіже повітря для Windows. Кватирка не замінює Windows, а доводить його до ладу: прибирає рекламу, нав'язані програми й зайве стеження, вмикає корисне, а все рідне (Пуск, панель задач, Провідник, оновлення, Store, драйвери) працює як завжди. Тому працює все, що працює у Windows, зокрема ігри з античитами на рівні ядра.

Головне правило – нічого не ламати:

- лише налаштування, які Windows сама підтримує (правила груп і параметри), без вимикання служб, правок системних файлів і «прискорювачів»;
- кожне покращення вимикається окремим перемикачем, і тоді Windows знову такий, як був;
- **охоронець** після оновлень Windows повертає ваш вибір, якщо оновлення його скинуло.

Кватирка складається з двох частин:

- **`Kvatyrka.exe`** – вікно з усіма покращеннями для вже встановленого Windows;
- **збирач**, який робить з офіційного ISO Windows 11 образ, де все це вже зроблено ще до першого входу.

## Kvatyrka.exe

Один файл, нічого встановлювати не треба. Запустіть – і побачите розділи:

- **Головне:** скільки рекомендованих покращень увімкнено, кнопки «Увімкнути рекомендоване» й «Повернути як у Windows», охоронець, тема вікна.
- **Покращення** за розділами – перемикачі з поясненням, що саме зміниться. Що стосується всього ПК, Windows попросить підтвердити правами адміністратора.
- **Програми:** знайдені нав'язані програми (Copilot, Clipchamp, Новини, рекламні ігри тощо). Прибираються для всіх користувачів, повернути будь-яку можна з Microsoft Store.
- **Острів:** за бажанням – капсула Кватирки замість панелі задач (меню, програми, швидкі налаштування, годинник). Типово вимкнений.

Якщо зміна з'явиться лише після перезапуску Провідника, повторного входу чи перезавантаження, Кватирка скаже про це й запропонує зробити це однією кнопкою.

**Охоронець** встановлює Кватирку в `Program Files`, додає ярлик у Пуск і запускається разом із Windows: при вході – для ваших налаштувань, після запуску ПК від імені системи – для спільних. Працює лише тоді, коли Windows оновився, і повертає тільки те, що ви вибрали в Кватирці, – зміни, які ви зробили самі в Параметрах, лишаються.

Перед першою зміною Кватирка запам'ятовує, як було, і при вимкненні повертає рівно те саме, навіть якщо там стояло щось нестандартне.

### Покращення

Усі покращення описані в одному файлі [`catalog/catalog.json`](catalog/catalog.json): назва, пояснення й точні записи реєстру для увімкнення й повернення. Той самий каталог використовують і вікно, і збирач.

**Пуск і панель задач.** Пуск без реклами й порад (рекомендовано); Пошук лише на комп'ютері (рекомендовано); Без нещодавніх файлів; Пошук на панелі задач (рекомендовано – значок); Значки на панелі задач (ліворуч чи по центру); Без віджетів і новин (рекомендовано); Без кнопки «Подання завдань» (рекомендовано); Без Copilot у Windows (рекомендовано); «Завершити завдання» на панелі (рекомендовано); Секунди на годиннику.

**Провідник.** Відкривати «Цей ПК» (рекомендовано); Показувати розширення файлів (рекомендовано); Без «Галереї» (рекомендовано); Повне меню правої кнопки.

**Реклама й підказки.** Параметри без реклами (рекомендовано); Без порад і «Завершіть налаштування» (рекомендовано); Без самовільних програм (рекомендовано); Екран блокування без реклами (рекомендовано); Своя картинка на екрані блокування; Провідник без реклами OneDrive (рекомендовано); Без запитів відгуків (рекомендовано).

**Приватність.** Мінімум діагностики (рекомендовано; для учасників Windows Insider не вмикається); Без реклами за вашими даними (рекомендовано); Без історії дій (рекомендовано); Без збору набраного тексту (рекомендовано); Без Recall (рекомендовано).

**Edge.** Edge без реклами й підказок (рекомендовано); Edge не працює у фоні (рекомендовано); Edge без бічної панелі (рекомендовано).

**Ігри й миша.** Миша без прискорення; Без фонового запису ігор; Без вікна залипання клавіш.

**Система.** Попереджати про перезавантаження (рекомендовано); Автозапуск без затримки (рекомендовано); Без самовільного шифрування диска (рекомендовано); Ізоляція ядра; Без швидкого запуску; Без гібернації; Драйвери не з Windows Update; Без точок відновлення.

Рекомендовані – ті, що прибирають зайве й нічого не забирають. Решта залежить від ПК і звичок, тож вмикаєте самі.

### Параметри запуску

| Параметр | Що робить |
| --- | --- |
| без параметрів | Відкриває вікно Кватирки (якщо вона вже працює – показує його) |
| `--startup` | Для автозапуску: охоронець повертає ваші налаштування, далі острів, якщо увімкнений |
| `--enforce-machine` | Для охоронця від імені системи: повертає спільні налаштування |
| `--elevated …` | Доручення з правами адміністратора; приймає лише покращення й програми з каталогу |
| `--image <профіль> <папка>` | Для збирача: застосовує профіль до відкритого образу |
| `--preview` | Показує острів, але не чіпає панель Windows |
| `--restore` | Повертає панель задач Windows і завершується |
| `--snapshot <папка>` | Зберігає знімки вікна, острова й панелей у PNG, нічого не змінюючи |

Налаштування вікна й острова лежать у `%APPDATA%\Kvatyrka\settings.json`, журнал – поруч, у `kvatyrka.log`; журнал змін з правами адміністратора й охоронця – у `%ProgramData%\Kvatyrka\kvatyrka.log`. Вибір покращень зберігається в реєстрі (`HKCU\Software\Kvatyrka\Tweaks` і `HKLM\SOFTWARE\Kvatyrka\Tweaks`) – саме його охоронець і повертає.

## Збирач образу

Потрібні Windows 10 або 11, права адміністратора, 25 ГБ вільного місця й офіційний ISO Windows 11 з [сайту Microsoft](https://www.microsoft.com/software-download/windows11).

```powershell
.\builder\Build-Kvatyrka.ps1 -Iso D:\Win11.iso                    # універсальний профіль
.\builder\Build-Kvatyrka.ps1 -Iso D:\Win11.iso -Config gigant     # свій профіль
.\builder\Build-Kvatyrka.ps1 -Iso D:\Win11.iso -Check             # лише показати, що буде зроблено
```

Перед збиранням покладіть `Kvatyrka.exe` у `builder\shell\`: він застосовує покращення до образу й ставиться в нього разом з охоронцем. Готовий ISO з'явиться в `builder\out\`, його можна записати на флешку, наприклад, Rufus.

### Профілі

Профіль у `builder\profiles\*.json` визначає все. Скопіюйте `universal.json`, змініть під себе й передайте його назву або шлях у `-Config`.

| Поле | Що задає |
| --- | --- |
| `edition` | Редакція: `Home`, `Pro`, `Education`, `Enterprise`, `ProWorkstations` |
| `keepApps` | Вбудовані програми, що лишаються (решта прибирається), можна з `*` |
| `image` | Лише для нового образу: `localAccount`, `removeOneDrive`, `blockOutlookAndDevHome`, `recoveryEnvironment` |
| `tweaks` | Покращення з каталогу: `recommended` (усі рекомендовані), `on` і `off` (id з каталогу), `choices` (напр. `"taskbar.search": "hidden"`) |
| `registry` | Власні значення реєстру, що ставляться один раз (напр. тема чи швидкість миші): `key`, `name`, `type`, `value` |
| `folders` | Папки, які треба створити |
| `drivers` | Папка з драйверами (`.inf`) для вбудовування, відносно `builder\` |
| `wallpaper` | Шпалери за замовчуванням, відносно `builder\`; порожньо – залишити шпалери Windows |
| `packages` | Компоненти Microsoft для першого запуску: `name`, `url`, `args` |
| `kvatyrka` | Чи ставити Кватирку з охоронцем |

Компоненти завантажуються лише з офіційних адрес. Перед вбудовуванням збирач перевіряє, що кожен файл підписаний Microsoft, і зупиняється, якщо це не так. Якщо профіль прибирає Game Bar, у `tweaks.on` має бути `games.noCapture` – інакше Windows проситиме встановити його в кожній грі, і збирач про це попередить.

**Локальний акаунт.** Якщо на екрані входу немає варіанта без інтернету, натисніть Shift+F10 і введіть `start ms-cxh:localonly`.

## Будова репозиторію

| Папка | Вміст |
| --- | --- |
| `catalog/` | Каталог покращень і програм – одне джерело для вікна й збирача |
| `core/` | Рушій покращень: стан, застосування, повернення, охоронець, профілі (C#, .NET 10) |
| `shell/` | Kvatyrka.exe: вікно, острів, права адміністратора (C#, WPF) |
| `builder/` | Збирач образу й профілі |
| `design/` | Джерело дизайну: макети, дизайн-система, іконки |
| `tests/` | Тести рушія й каталогу, перевірка збирача без Windows |

Дизайн має одне джерело: `design/mockups.py`. З нього генеруються макети, дизайн-система й іконки (`python design/icons_cs.py`), тож вони не розходяться між собою.

## Збірка й перевірка

```powershell
dotnet test tests/Kvatyrka.Core.Tests
dotnet build shell/Kvatyrka.Shell -c Release
dotnet publish shell/Kvatyrka.Shell -c Release -o publish -p:SelfContained=true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Тести перевіряють, що кожне покращення вмикається й повертається рівно до попереднього стану, що охоронець чіпає лише вибране, а профілі збирача коректні. GitHub на кожен коміт запускає тести, збирає Kvatyrka.exe, робить знімки вікна й острова та перевіряє збирач у PowerShell 7 і Windows PowerShell 5.1.

**Kvatyrka** makes Windows 11 right without replacing it: it removes ads, bloatware and needless telemetry using only settings Windows itself supports, keeps Start, the taskbar, Explorer, updates and drivers intact, and lets you undo every change with its own switch. A guardian re-applies your choices after Windows updates. The same catalog of improvements powers `Kvatyrka.exe` for an installed system and an image builder that turns an official Windows 11 ISO into a clean one. An optional "island" can replace the taskbar.
